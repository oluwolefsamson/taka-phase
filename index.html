Mock API Service Layer

mockAuthApiMock API
  • sendOTP(phone) — simulates SMS dispatch (1s delay)
  • verifyOTP(phone, code) — accepts any 6-digit code (1.5s delay)
  • validateSponsorCode(code) — validates against known codes, returns upline name
  • registerUser(data) — creates mock user object, returns auth token
mockWalletApiMock API
  • getBalance() — returns ₦287,450.00
  • getTransactions() — returns 12-item transaction array
  • getVirtualCard() — returns Verve card object
  • getBankAccounts() — returns 2 saved accounts
  • transfer(to, amount, narration) — 1.5s delay, returns new debit transaction
  • withdraw(bankAccountId, amount) — calculates fee, returns new withdrawal transaction
  • fundWallet(amount) — returns new credit transaction
  • toggleCardFreeze(cardId) — toggles frozen state
mockNetworkApiMock API
  • getStats() — returns full NetworkStats object (rank, team, earnings, referralCode)
  • getDirectRecruits() — returns 8-member array
  • getCommissions() — returns 12-commission array
  • getLeaderboard(period) — returns weekly or monthly 10-entry array
mockShopApiMock API
  • getProducts() — returns all 10 products
  • getProductById(id) — returns single product or null
  • getOrders() — returns seeded orders + session-placed orders
  • placeOrder(items, address, paymentMethod) — generates new order with auto-incrementing ID, free delivery on orders ≥ ₦10,000
  • getSalesStats() — returns ₦287,500 monthly stats with weekly breakdown
  • getContentAssets() — returns 8 branded assets
